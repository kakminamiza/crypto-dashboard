📐 Probability Lab

คำนวณ odds/เป確率เข้า TP/TP2/SL จากราคาปัจจุบัน + ระดับ E/TP/SL (ATR-based)
สูตร: P(hit TP) = (Target - Current) / (ATR×1.5), clamp 0-100% · SL น้อยกว่า Current = ความเสี่ยงสูงสุด
📐 Probability(hit TP before SL) = MAX(0, MIN(1, (Target − Current) / (ATR×1.5)))
📉 P(hit SL first) = 1 − P(hit TP)
💰 R:R คาดหวัง = P(hit TP)×(Reward) − P(hit SL)×(Risk)
